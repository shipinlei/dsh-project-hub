# 截图目录

README 与 GitHub Social preview 使用以下文件（替换时保持同名即可）：

| 文件 | 内容 | 建议用途 |
|---|---|---|
| `social-preview.png` | 真实界面整窗截图（侧栏按项目分组 + 项目工作台面板），**1280×640（2:1）** | README 首图；GitHub 仓库 Settings → Social preview 上传 |
| `project-panel.png` | 项目工作台面板特写 | README「截图」明细 |
| `sidebar-grouped.png` | 侧栏会话按项目（工作区）分组 | README「截图」明细 |

说明：

- 三张图来自同一张真实界面截图（2026-11-11）的裁切与缩放；图中**本机路径已像素化打码**，项目名保留；
- 更新截图时：面板截图存 `project-panel.png`、侧栏截图存 `sidebar-grouped.png`，Social preview 用 1280×640；
- 不要把 API Key、token、会话正文等敏感内容截进图里。
