# 截图目录

README 引用两张截图，文件名为固定约定（替换时保持同名即可）：

| 文件 | 内容 | 建议 |
|---|---|---|
| `project-panel.png` | 「项目」工作台面板：记忆条、侧栏排序条、若干项目卡片与会话 | 1280–1600px 宽，浅色主题 |
| `sidebar-grouped.png` | 侧栏会话按项目（工作区）分组，组内按时间倒序 | 竖图 600–900px 宽 |
| `social-preview.png` | GitHub 仓库 Social preview（1280×640） | 上传到仓库 Settings → Social preview |

截图要求：

1. 用真实 DSH 界面（桌面或 Web 均可），不要出现 API Key、token、会话正文等敏感信息；
2. 项目名/路径可打码或替换成示例项目；
3. 建议 PNG，非必要不压缩；保持界面清晰可读。

当前仓库里的三张是**生成的占位图/示意图**（前两张带「截图占位图」字样）。换成真实截图后可直接删除本文件里的占位说明。
