# v0.1.0 发布说明（GitHub Release 正文草稿）

> 直接复制本文件内容作为 GitHub Release 的正文；创建 tag 时用 `v0.1.0`。

首个公开版本：把「项目」变成 DSH 组织会话的单位。

## 亮点

- **项目工作台面板**：侧栏「项目」入口，按最近活跃列出项目卡片与会话，组内按时间倒序；
- **项目级默认设置**：每个项目可存描述 / preset / 模型 / 推理强度，「新建会话」自动套用；
- **项目记忆隔离**：一键把 Mnemon 记忆作用域切到按工作区隔离，`USER.md` 保持全局，可一键回滚；
- **项目规则预览**：按官方 `AGENTS.md` / `CLAUDE.md` 发现顺序只读预览；
- **侧栏会话按项目分组**：启动即切换到官方「按工作区」分组，兼容 Claude Code 风格皮肤的日期视图，可「不干预」。

## 安装

```text
plugin_manager(action="install_bundle", target="<本仓库绝对路径>")
```

或：

```powershell
git clone https://github.com/shipinlei/dsh-project-hub.git
dsh plugin --profile desktop add "link:<本仓库绝对路径>"
```

安装后刷新一次 Web GUI 页面，侧栏出现「项目」。详见 [README](README.md)。

## 兼容性

- DSH `>=0.2.0-rc.2 <0.3.0`（实测 0.2.2-rc.1 desktop / Windows）；
- 零构建、不修改 DSH 核心、不替换官方侧栏槽位。

## 已知限制

- 不支持跨项目移动会话（平台无此接口）；
- 不做内置编辑器（规则/记忆只读预览）；
- 权限模式不纳入项目级设定。

完整变更见 [CHANGELOG.md](CHANGELOG.md)。
